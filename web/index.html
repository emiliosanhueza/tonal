Formats Tonal understands

CSV or TSV with headers — e.g. a spreadsheet export. Columns are matched by name: Title/Song Artist BPM Key Notes Tags Energy Rating Length.

One song per line — separate fields with commas, tabs or |:

Artist - Title, BPM, Key

JSON — a Tonal backup, an export from your earlier Tonal / Harmonic Mix Table files (playlists come along too), or any array of song objects.

Keys can be written as Am F#m Db E♭ Dorian A♭ Mixolydian 8A (Camelot) or 5m (Open Key).

Backup & export

Your library lives in tonal.db. A dated copy goes into backups/ every day you open Tonal.

Add songs from Terminal

From the Tonal folder:

python3 tonal.py add "Praise You" "Fatboy Slim" --bpm 109 --key "Ab mixolydian"
python3 tonal.py import my-songs.csv
python3 tonal.py list --key 3B
